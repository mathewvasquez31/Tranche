# Celestia Travels and Tours

Celestia Travels and Tours is a frontend travel agency website prototype inspired by the world of Teyvat. The website presents travel destinations, attractions, and travel information for visitors interested in exploring the seven nations of Teyvat.

## Project Overview

This project was developed as an academic frontend project using **HTML and CSS**. It serves as a visual and interactive pitch for a fictional travel agency, focusing on destination presentation and user experience.

The website includes:

- Homepage with agency introduction and director details
- Featured destinations
- Information about the seven nations of Teyvat
- Featured attractions and travel highlights
- Travel packages and destination information
- FAQ and contact sections
- Responsive frontend design

## Destinations

Celestia Travels and Tours covers the following seven nations:

- Mondstadt
- Liyue
- Inazuma
- Sumeru
- Fontaine
- Natlan
- Snezhnaya

## Technologies Used

- HTML5
- CSS3

## Project Scope

This version is a **frontend-only prototype** created for an academic project and presentation pitch. Booking, payment, user accounts, and other backend functionality are not currently implemented.
